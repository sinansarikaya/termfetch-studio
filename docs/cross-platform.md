# TermFetch Studio v2 — Cross-Platform Guide

TermFetch Studio v2 is designed to run seamlessly across Linux distributions, macOS, and Windows. This guide covers installation, terminal configuration, prerequisites, and platform-specific details.

---

## Prerequisites

1. **Fastfetch** (Recommended v2.10.0+):
   - **Linux (Arch):** `sudo pacman -S fastfetch`
   - **Linux (Ubuntu/Debian):** `sudo add-apt-repository ppa:zhangsongcui3371/fastfetch && sudo apt update && sudo apt install fastfetch`
   - **Linux (Fedora):** `sudo dnf install fastfetch`
   - **macOS:** `brew install fastfetch`
   - **Windows:** `winget install --id Fastfetch-cli.Fastfetch` or `scoop install fastfetch`
2. **Nerd Font:**
   - Install any Nerd Font (e.g., JetBrainsMono Nerd Font, FiraCode Nerd Font, Hack Nerd Font) for icons and system glyphs.

---

## Installation & Running

### Building from Source (All Platforms)

```bash
git clone https://github.com/sinansarikaya/termfetch-studio.git
cd termfetch-studio
cargo build --release
```

The resulting binary will be located at:
- **Linux / macOS:** `target/release/termfetch-studio`
- **Windows:** `target\release\termfetch-studio.exe`

### Prebuilt Binaries

Prebuilt binaries are generated by our multi-platform CI workflow:
- `termfetch-studio-linux-x86_64-gnu`: Dynamic binary for modern glibc-based Linux (Arch, Ubuntu 22.04+, Fedora, openSUSE).
- `termfetch-studio-linux-x86_64-musl-static`: Fully static binary with no glibc dependency (Alpine Linux, older Debian/RHEL, containers).
- `termfetch-studio-macos-universal`: macOS binary for Apple Silicon (M1/M2/M3/M4) and Intel Macs.
- `termfetch-studio-windows-x64`: Native Windows 64-bit executable.

## Platform Details

### 1. Linux
- **Configuration Paths:**
  - Config: `~/.config/termfetch-studio`
  - Fastfetch Target: `~/.config/fastfetch/config.jsonc` and `~/.config/termfetch-studio/fastfetch.jsonc`
- **Terminal Graphics Protocols:**
  - Full Kitty Protocol: Kitty, Ghostty, WezTerm
  - Sixel Graphics: Foot, mlterm
  - Half-Block & Chafa Fallback: Alacritty, GNOME Terminal, Konsole, XFCE Terminal

### 2. macOS
- **Configuration Paths:**
  - Config: `~/.config/termfetch-studio`
  - Fastfetch Target: `~/.config/fastfetch/config.jsonc`
- **Package Manager Binary Auto-Discovery:**
  - TermFetch Studio automatically looks up `/opt/homebrew/bin/fastfetch` (Apple Silicon Homebrew), `/usr/local/bin/fastfetch` (Intel Homebrew), and `/opt/local/bin/fastfetch` (MacPorts), even if they are omitted from the default GUI environment PATH.
- **Recommended Terminal:**
  - Ghostty, Kitty, or iTerm2 for optimal TrueColor and image support.

### 3. Windows
- **Configuration Paths:**
  - Automatically checks `%APPDATA%\fastfetch\config.jsonc` first. If present, modifies that file. Otherwise defaults to `%USERPROFILE%\.config\fastfetch\config.jsonc`.
  - TermFetch Studio Config: `%USERPROFILE%\.config\termfetch-studio\settings.json`.
- **PowerShell Integration:**
  - Fastfetch can be added to your PowerShell profile:
    ```powershell
    # In Documents\PowerShell\Microsoft.PowerShell_profile.ps1
    fastfetch
    ```
- **Recommended Terminal:**
  - Windows Terminal (v1.20+) running PowerShell 7 or Windows PowerShell with a Nerd Font configured.

## Diagnostics (Doctor Screen)

Run the built-in diagnostic checker at any time:

```bash
termfetch doctor
# or
termfetch --doctor
```

This verifies:
- Fastfetch installation & version
- Configuration file readability & JSONC validity
- Write permissions for settings and backup locations
- Shell integration (bash, zsh, fish, PowerShell)
- Nerd Font installation
- Terminal geometry and image protocol capabilities
